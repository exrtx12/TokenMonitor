# AI Usage Monitor

claude.ai와 ChatGPT의 **남은 사용량**을 바탕화면 한구석에 항상 띄워두는 작은 Windows 위젯입니다.

"지금 5시간 한도를 얼마나 썼더라?", "주간 한도는 언제 풀리지?"를 브라우저를 열지 않고 바로 확인할 수 있습니다.

---

## 1. 설치하기

둘 중 편한 쪽 하나만 받으면 됩니다.

| | 파일 | 특징 |
|---|---|---|
| **설치형** (추천) | `AI Usage Widget Setup 0.3.0.exe` | 시작 메뉴에 등록되고, 윈도우 켤 때 자동 실행 설정이 가능합니다. 나중에 설정에서 깔끔하게 제거할 수 있습니다 |
| 포터블 | `AI Usage Widget 0.3.0.exe` | 설치 없이 더블클릭하면 바로 실행됩니다 |

### "Windows에서 PC를 보호했습니다" 파란 화면이 뜬다면

정상입니다. 개인이 만든 앱이라 유료 코드 서명 인증서가 없어서 나오는 경고이지, 바이러스가 검출된 게 아닙니다.

**추가 정보** → **실행**을 누르면 진행됩니다.

---

## 2. 처음 한 번: 로그인

실행하면 화면 오른쪽 아래에 위젯이 뜨고, 작업 표시줄 오른쪽 트레이에도 아이콘이 생깁니다.
아직 로그인 전이라 사용량 자리에는 **"로그인이 필요합니다"** 가 보일 겁니다.

1. 위젯에 있는 **로그인 창 열기** 버튼을 누릅니다.
   (또는 트레이 아이콘 우클릭 → `Claude 로그인 창 열기` / `ChatGPT 로그인 창 열기`)
2. 열린 창에서 **본인 계정**으로 평소처럼 로그인합니다.
3. 그 창을 닫으면 바로 사용량을 읽어옵니다.
4. Claude와 ChatGPT는 **각각 따로** 로그인해야 합니다.

로그인은 한 번만 하면 됩니다. 앱을 껐다 켜도, PC를 재부팅해도 유지됩니다.

---

## 3. 화면 읽는 법

서비스마다 카드가 하나씩 있고, 카드 안에 막대가 두 개 있습니다.

- **세션 (5시간)** — 짧게 몰아 쓸 때 걸리는 단기 한도
- **주간 (7일)** — 일주일 단위 장기 한도

각 막대에서:

| 위치 | 의미 |
|---|---|
| 막대 오른쪽 숫자 | 지금까지 쓴 비율(%). **80%를 넘으면 막대가 빨갛게** 바뀝니다 |
| 막대 아래 왼쪽 | 한도가 초기화되는 **시각(한국 시간)** |
| 막대 아래 오른쪽 | 초기화까지 **남은 시간** (1초마다 갱신) |
| 카드 맨 아래 | 값을 마지막으로 읽어온 시각 |

사용량은 **5분마다 자동으로** 갱신됩니다.

> **카운트다운이 줄지 않고 늘어날 때가 있습니다.** 고장이 아닙니다.
> 이 한도는 "정해진 시각에 일괄 초기화"가 아니라 쓸수록 초기화 시점이 뒤로 밀리는 방식(롤링 윈도우)이라 그렇습니다.

## 4. 평소 사용법

### 위젯 창

- 위쪽 제목 부분을 **드래그**해서 원하는 자리로 옮길 수 있고, 그 위치를 기억합니다
- **↻** — 지금 바로 새로고침
- **─** — 위젯 숨기기 (앱은 트레이에서 계속 돕니다)

### 트레이 아이콘

- **좌클릭** — 위젯 보이기/숨기기
- **우클릭** — 메뉴

| 메뉴 | 설명 |
|---|---|
| 지금 새로고침 | 5분을 기다리지 않고 즉시 갱신 |
| Claude / ChatGPT 로그인 창 열기 | 로그인하거나, 세션이 풀렸을 때 다시 로그인 |
| 위젯 항상 위 | 다른 창에 가리지 않게 맨 앞에 고정 |
| 위젯 표시 | 위젯 보이기/숨기기 |
| **표시할 서비스** | 위젯에 보일 AI를 하나씩 켜고 끕니다 (아래 참고) |
| 윈도우 시작 시 실행 | PC를 켜면 자동으로 실행 |
| **종료** | 앱을 **완전히** 끕니다 |

> `─`(숨기기)는 앱을 끄는 게 아닙니다. 완전히 끄려면 트레이 우클릭 → **종료**를 쓰세요.

### 쓰는 AI만 골라서 보기

트레이 우클릭 → **표시할 서비스**에서 원하는 것만 체크하면 됩니다.

- 체크를 풀면 그 카드가 위젯에서 사라지고, 사용량도 더 이상 확인하지 않습니다.
- **로그인은 그대로 남습니다.** 나중에 다시 켜도 로그인을 새로 할 필요가 없습니다.
- 전부 끄면 위젯이 작아지면서 안내 문구만 남습니다.
- **Gemini**는 목록에 있지만 아직 **준비 중**이라 기본으로 꺼져 있습니다. 켜면 카드는 보이지만
  사용량 대신 "지원 준비 중입니다."가 표시됩니다.

### 알림

한도가 실제로 초기화되면 윈도우 알림이 한 번 뜹니다.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| **"로그인이 필요합니다"** | 로그인 세션이 만료된 겁니다. **로그인 창 열기**를 눌러 다시 로그인하세요 |
| 사용량이 계속 `-` 로만 나옴 | **다시 시도** 버튼을 누르고, 인터넷 연결을 확인하세요 |
| **위젯이 사라졌어요** | 트레이 아이콘을 **좌클릭**하면 다시 나옵니다 |
| 트레이 아이콘이 안 보여요 | 작업 표시줄의 **`^`(숨겨진 아이콘 표시)** 안에 들어가 있습니다. 밖으로 끌어내면 항상 보입니다 |
| **Gemini 사용량이 안 나와요** | 아직 지원 준비 중입니다. 사용량을 가져올 방법이 확인되면 업데이트로 추가됩니다 |
| **"조직이 여러 개 감지되었습니다"** (Claude) | 회사·팀 계정이 섞여 있을 때 나옵니다. 표시된 버튼에서 쓸 조직을 고르세요. 나중에 카드의 **⚙** 버튼에서 바꿀 수 있습니다 |
| **"응답 형식이 변경된 것 같습니다"** | Claude·ChatGPT 쪽 API가 바뀐 경우입니다. 앱을 고쳐야 해서, 배포해준 사람에게 알려주세요 |
| 껐는데 계속 떠 있어요 | 트레이 우클릭 → **종료** |
| 위젯이 화면 밖으로 나갔어요 | 트레이 우클릭 → 종료 후 다시 실행하면 기본 위치(우하단)로 돌아옵니다 |

## 6. 개인정보 · 보안

- 로그인 정보는 **본인 PC에만** 저장됩니다 (`%APPDATA%\ai-usage-widget`).
- 배포한 사람을 포함해 **누구에게도 전송되지 않습니다.** 앱 안에 배포자의 계정 정보도 들어있지 않습니다.
- 앱이 접속하는 곳은 **켜 둔 서비스의 사이트뿐**이며(claude.ai / chatgpt.com), 그중에서도 **사용량 조회 API만** 호출합니다.
  끈 서비스에는 아무 요청도 보내지 않습니다.
- **대화 내용은 읽지 않습니다.** 가져오는 건 사용률 숫자와 초기화 시각이 전부입니다.
- 별도 서버가 없습니다. 각자 자기 PC에서 자기 계정으로만 동작합니다.

---

## 7. 제거하기

- **설치형** — 설정 → 앱 → 설치된 앱 → **`AI Usage Widget`으로 시작하는 항목** (예: `AI Usage Widget 0.3.0`) → 제거
- **포터블** — exe 파일만 지우면 끝

로그인 정보와 설정까지 완전히 지우려면, 위 작업 후 `%APPDATA%\ai-usage-widget` 폴더를 삭제하세요.
(탐색기 주소창에 `%APPDATA%` 를 붙여넣으면 바로 이동합니다.)

---

## 8. 알려진 제한

- **Windows 전용**입니다 (macOS·Linux 빌드 없음).
- **자동 업데이트가 없습니다.** 새 버전은 파일을 다시 받아 설치해야 합니다.
- 백그라운드에서 메모리를 **약 340MB** 사용합니다. Electron(크로미움) 기반이라 이보다 더 줄이기는 어렵습니다.
- **Gemini는 아직 지원하지 않습니다.** 목록에는 있지만 사용량은 표시되지 않습니다.
  Claude·ChatGPT와 달리 Gemini에는 사용량을 알려주는 창구가 확인되지 않아서, 확인되는 대로 붙일 예정입니다.
- 코드 서명이 없어 설치할 때마다 SmartScreen 경고가 뜹니다.
